# OffGrid

Chatten ohne Mobilnetz. OffGrid verbindet Android-Handys über LoRa-Funk –
eine kleine ESP32-Antenne am USB-C-Anschluss, Ende-zu-Ende verschlüsselt.

| Repo | Inhalt |
|---|---|
| [app](https://github.com/OffGridCH/app) | Android-App (Ionic, Angular, Capacitor) |
| [firmware](https://github.com/OffGridCH/firmware) | Firmware des esp32-s3 basierten Gerät |
